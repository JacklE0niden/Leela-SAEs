# Language Model SAEs UI

React UI for exploring BT4 SAE features and the interaction circuit view.

## Main Views

- `Features`: browse dictionaries and inspect feature details.
- `Dictionaries`: inspect available SAE dictionaries.
- `Bookmarks`: revisit saved features.
- `Interaction Circuit`: view interaction graph structure and connected features.

## Development

### Prerequisites

- Node.js 18+
- Bun or npm

### Setup

```bash
cd ui
bun install
bun run dev
```

### Build

```bash
bun run build
```
